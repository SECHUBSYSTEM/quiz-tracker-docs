## 2026-10-23

Setup changes in [commit 2899564](https://github.com/SECHUBSYSTEM/quiz-tracker/commit/2899564).
If you cloned before this date, update your commands.

- **Create `.env` before `pnpm install`.** The install runs `prisma generate`,
  which needs `DIRECT_URL`. The old order failed on a fresh clone.
- **The migration script is now `pnpm run db:setup`.** It was `pnpm setup`,
  which collides with a built-in pnpm command.
- **pnpm 11 is the stated requirement**, matching the version pinned in
  `package.json`.
- **`GET /api/health` is now documented.**
- **Quiz Tracker is MIT licensed.**
